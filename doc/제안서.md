# 가상 스크리닝 벤치마크의 인위적 성능 편향(Artificial Enrichment) 정량 진단 도구 개발

## 1. 문제 정의

### 1.1 풀고자 하는 문제

구조/리간드 기반 가상 스크리닝(Structure-/Ligand-Based Virtual Screening, SBVS/LBVS) 모델은 표준 벤치마크 데이터셋(DUD-E, LIT-PCBA, PDBbind 파생 세트 등) 위에서 성능(AUROC, Enrichment Factor 등)을 보고하며 우수성을 주장한다. 그러나 이 벤치마크들은 "액티브(실제 결합 화합물)"와 "디코이(비결합으로 가정된 화합물)"를 구성하는 과정에서 다음과 같은 구조적 결함을 내포한다.

- **물성 편향(physicochemical bias)**: 디코이가 액티브와 분자량·logP·수소결합공여/수용체 수 등에서 통계적으로 구분되어, 실제 결합 정보 없이도 물성만으로 분류가 가능해진다.
- **골격 편향(scaffold bias)**: 디코이가 액티브와 위상학적으로(Bemis-Murcko scaffold 기준) 뚜렷이 분리되어, 화학 구조의 "종류"만으로 분류가 가능해진다.
- **분석적 기억 편향(analogue/nearest-neighbor bias, AVE bias)**: 액티브-액티브 간 화학적 유사도가 액티브-디코이 간 유사도보다 체계적으로 높아, 실제 결합 메커니즘을 학습하지 않고 최근접 이웃(nearest-neighbor) 수준의 암기만으로도 벤치마크에서 높은 점수를 받을 수 있다.

이 세 가지 편향이 존재하면, 모델이 보고하는 고성능 지표는 **결합 친화도를 실제로 예측하는 능력**이 아니라 **벤치마크 구성 과정에서 우연히 섞여 들어간 지름길(shortcut) 신호를 암기하는 능력**을 반영할 뿐이다. 이는 이미 여러 문헌에서 개별 사례로 지적된 바 있으나(§2 참고), *어느 정도로* 편향되어 있는지를 여러 데이터셋·여러 타깃에 걸쳐 **일관된 수치로 비교**할 수 있는 표준화된 진단 도구는 아직 부재하다.

### 1.2 가치

1. **벤치마크 신뢰도 사전 검증**: 새로 구축하거나 채택하려는 액티브/디코이(또는 생성모델이 만들어낸 네거티브 후보) 세트가 실제로 유의미한 벤치마크인지, 아니면 편향으로 인해 인위적으로 쉬운 문제인지를 사용 전에 정량적으로 진단할 수 있다.
2. **기존 SOTA 재평가의 근거 제공**: DUD-E 등에서 보고된 딥러닝 기반 SBVS 모델의 고성능이 편향에서 기인한 것인지, 실제 일반화 성능인지 재해석할 수 있는 정량적 근거(타깃별 편향 점수와 보고된 성능 간 상관관계)를 제공한다.
3. **확장성**: 본 프로젝트의 최종 목표인 "생성모델이 만든 단백질-리간드 3D 구조 중 결합도가 정상 범위인 것만 선별"하는 문제로 직결된다. 생성모델이 만든 네거티브/디코이 후보가 물성·골격·화학공간 상에서 액티브와 부자연스럽게 분리되어 있다면, 이는 실제 "비결합"이 아니라 생성모델의 편향된 샘플링 아티팩트일 가능성이 높다. 본 도구는 이런 생성 결과물에도 동일한 3지표를 적용해 "정상적으로 분포된" 결합/비결합 쌍만 남기는 필터로 재사용될 수 있다.

### 2.2 본 프로젝트가 선행 연구와 다른 점

기존 연구들은 각각 하나의 편향 유형(물성 *또는* AVE)만 개별적으로 진단하거나, 특정 데이터셋(DUD-E)에 국한해 사례 분석을 수행했다. 본 프로젝트는

1. 물성·골격·AVE 세 지표를 **하나의 파이프라인**으로 통합해 타깃 단위로 동시에 산출하고,
2. DUD-E(편향 의심), LIT-PCBA(저편향 설계), PDBbind(실측 "정상" 참조 분포)를 **같은 지표로 교차 비교**함으로써 지표 자체의 타당성도 함께 검증하며,
3. 향후 생성모델 산출물 필터링까지 재사용 가능한 **범용 진단 라이브러리**로 구현한다는 점에서 차별화된다.

## 3. 활용 데이터

### 3.1 DUD-E (Directory of Useful Decoys, Enhanced)

- **출처**: https://dude.docking.org/ (무료, 등록 불요)
- **규모**: 102개 타깃, 약 22,886개 액티브, 액티브당 약 50개 비율로 매칭된 약 1,411,214개 디코이
- **구조**: 타깃별 디렉토리 아래 `actives_final.ism`, `decoys_final.ism` (공백 구분 `SMILES ID` 텍스트)
- **확보 방안**: 타깃별 압축파일을 다운로드해 `data/raw/dude/<target>/` 레이아웃으로 배치 (이미 로더 구현 완료, §4.3)
- **역할**: "편향 의심" 데이터셋 — 본 도구로 편향이 실제로 검출되는지 확인하는 1차 대상

### 3.2 LIT-PCBA

- **출처**: https://drugdesign.unistra.fr/LIT-PCBA/ (무료)
- **규모**: PubChem HTS 데이터 기반 15개 타깃, 액티브/비활성 비율은 실제 실험 히트율을 반영(타깃별 상이, 대체로 DUD-E보다 액티브 비율이 낮고 더 현실적)
- **구조**: 타깃별 `actives.smi`, `inactives.smi` — "full" 세트와 AVE bias를 최소화하도록 선별한 "unbiased" 세트를 함께 배포
- **확보 방안**: `data/raw/litpcba/<target>/` 레이아웃으로 배치 (로더 구현 완료)
- **역할**: "저편향 설계" 대조군 — 동일 지표로 측정했을 때 DUD-E보다 편향 점수가 유의하게 낮게 나오는지가 지표 타당성 검증의 핵심 근거. 또한 같은 타깃의 "full" vs "unbiased" 세트 간 점수 차이 자체가 좋은 sanity check가 된다.

### 3.3 PDBbind (및 실제 사용한 대체 경로)

- **출처**: http://www.pdbbind.org.cn/ (무료지만 계정 등록 후 로그인해야 다운로드 가능 — 자동화된 파이프라인에서 무인 확보 불가)
- **규모**: General set 기준 약 19,443개 단백질-리간드 복합체(버전에 따라 상이), 실측 Kd/Ki/IC50 값 포함
- **구조**: 인덱스 파일(`INDEX_general_PL_data.<year>`, 공백 구분 컬럼: PDB code, 해상도, 발표연도, -logKd/Ki, affinity 문자열, 리간드명) + 복합체별 `<pdbid>_ligand.sdf`
- **확보 방안(공식 경로)**: 사용자가 직접 계정을 등록해 인덱스 파일과 리간드 구조 파일을 내려받아 `data/raw/pdbbind/` 레이아웃으로 배치하면 사용하도록 로더(`datasets/pdbbind.py`)는 구현해 두었으나, 실제 검증 단계에서 계정 없이 접근이 막혀 있음을 확인함.
- **실제 사용한 대체 경로**: RCSB PDB의 공개 REST/GraphQL API(`data.rcsb.org`, `search.rcsb.org`)는 로그인 없이 `rcsb_binding_affinity` 필드(출처: BindingDB, Binding MOAD, PDBbind 등 문헌 큐레이션 결합친화도 DB — PDBbind와 동일 계열의 실측 데이터)를 제공한다. `datasets/rcsb_affinity.py`에서 이 API로 실측 Ki/Kd/IC50이 붙은 복합체를 수집해 동일한 "실제 결합이 검증된 화합물" 참조 세트로 대체 사용했다(§5.3에 실제 검증 결과 수록). 정식 PDBbind 접근 권한이 확보되면 `datasets/pdbbind.py`로 그대로 교체 가능하도록 두 로더 모두 같은 `MoleculeSet` 인터페이스를 반환하게 설계함.
- **역할**: 실제 결합이 검증된 화합물들의 물성/골격/화학공간 분포 — DUD-E/LIT-PCBA의 액티브 세트가 이 "정상 분포"에서 벗어나 있는지 비교하는 외부 참조로 사용하며, 최종적으로는 생성모델이 만든 구조의 "정상 결합도" 판정 기준선으로 확장 활용.

## 4. 문제 해결 방법

### 4.1 접근 개요

각 벤치마크 타깃의 (액티브 집합, 디코이/비활성 집합) 쌍에 대해, 서로 독립적인 세 가지 지표를 계산하고 이를 종합해 "이 타깃의 벤치마크가 얼마나 인위적으로 쉬운가"를 정량화한다. 각 지표는 서로 다른 편향의 원천을 겨냥하도록 설계했으며, 하나의 지표만으로는 놓칠 수 있는 편향을 상호 보완적으로 검출한다(Sieg et al., 2019의 지적을 반영).

### 4.2 방법론 (지표별)

1. **물성 편향(Property bias)** — 액티브/디코이 각각의 분자량, logP, TPSA, 수소결합 공여/수용체 수, 회전가능결합 수, 형식전하, 방향족 고리 수 분포에 대해 Kolmogorov–Smirnov 통계량을 계산하고, 디스크립터 전체 평균을 0~1 스케일의 편향 점수로 사용한다. 어떤 디스크립터가 편향을 주도하는지 보기 위해 표준화된 Wasserstein distance도 함께 보고한다.
2. **골격 편향(Scaffold bias)** — Bemis-Murcko scaffold(RDKit `MurckoScaffold`)를 추출해 액티브/디코이 골격 집합 간 중첩도를 계산한다. 최초 구현은 단순 Jaccard(`1 - Jaccard`를 편향 점수로 사용)였으나, LIT-PCBA TP53 타깃(액티브 79개 vs 디코이 4,168개)으로 실제 검증하는 과정에서 **클래스 크기 불균형에 취약하다는 결함이 실증적으로 드러났다**: 디코이 쪽 분자 수가 53배 많다 보니 디코이의 고유 scaffold 수(1,194개)가 액티브(46개)보다 압도적으로 많아지고, 그 결과 Jaccard 분모(합집합)가 커져서 실제로는 액티브 scaffold의 39%(18/46개)가 디코이 풀에도 존재함에도 점수가 0.985로 거의 "완전 분리"처럼 나타났다. 이는 생태학의 rarefaction curve(개체 수를 더 뽑을수록 관찰되는 종 수가 늘어나는 것과 동일한 통계적 아티팩트)와 같은 문제다. 이를 반영해 **큰 쪽 집합을 작은 쪽 분자 수만큼 반복 무작위 서브샘플링(rarefaction, 기본 200회)한 뒤 평균 Jaccard**를 편향 점수의 기준으로 삼도록 수정했다(`1 - rarefied Jaccard`). 원본 raw Jaccard와 비대칭 coverage(`|A∩D|/|A|`)는 진단용 보조 지표로 함께 보고하며, 각 클래스 내 골격 집중도(정규화 엔트로피 기반)도 제공한다.
3. **AVE bias(클래스 간 거리/암기 편향)** — Wallach & Heifets(2018)의 정의를 그대로 구현: 액티브/디코이를 각각 무작위로 train/test 분할한 뒤, ECFP4(Morgan, radius=2, 2048 bit) 지문 기반 Tanimoto 유사도로 test 쪽 각 분자가 train 쪽 같은 클래스/다른 클래스에 얼마나 가까운지 최근접 이웃 유사도로 측정한다. `AVE = (NN_AA − NN_AI) + (NN_II − NN_IA)`. 분할의 무작위성에 따른 잡음을 줄이기 위해 반복 무작위 분할(기본 10회) 평균과 표준편차를 함께 보고한다.

### 4.3 참고/재사용 가능한 코드베이스

본 저장소(`src/proteinanomaly/`)에 이미 위 방법론의 참조 구현을 완료했다.

- `datasets/dude.py`, `datasets/litpcba.py`: DUD-E/LIT-PCBA 공식 배포 포맷 로더 (AMPC, TP53 실제 데이터로 검증 완료)

- `pipeline.py`, `scripts/run_diagnosis.py`: 타깃 단위 3지표 진단 실행 및 CSV/JSON 리포트 생성 CLI
- `scripts/fetch_rcsb_binding_reference.py`: RCSB 참조 세트 수집 CLI
- `scripts/compare_actives_to_reference.py`: 특정 타깃의 액티브 세트를 RCSB(PDBbind 대체) 참조 세트와 비교하는 CLI (§5.1 "PDBbind 대비 액티브 분포의 이질성" 평가 항목의 실행 도구)
- `tests/`: 합성 분자 세트(스캐폴드/물성이 의도적으로 일치하는 케이스 vs 의도적으로 분리된 케이스, 클래스 크기 불균형을 인위적으로 희석시킨 케이스)로 각 지표의 방향성과 size-imbalance 강건성을 검증하는 단위 테스트 15건 확보 완료, 전부 통과

### 4.4 향후 확장

- 파이프라인에서 산출한 편향 점수를, 동일 타깃에 대해 문헌에 보고된 SBVS/LBVS 모델 성능(AUROC, EF1%)과 상관분석하여 "편향이 성능에 실제로 기여하는지"를 정량 검증하는 단계로 확장한다(§5.1).
- 생성모델(예: 디퓨전 기반 리간드/포즈 생성기)이 산출한 네거티브 후보에도 동일한 3지표를 적용해, 물성·골격·화학공간상 액티브와 부자연스럽게 분리된 "가짜 네거티브"를 걸러내는 필터로 재사용한다.

## 5. 평가 방법

### 5.1 정량 평가

| 지표 | 측정 대상 | 방법 |
|---|---|---|
| 지표 자체의 타당성(construct validity) | 물성/골격/AVE 편향 점수 | DUD-E(편향 의심) vs LIT-PCBA(저편향 설계) 동일 타깃 비교 시, DUD-E 점수가 유의하게 높아야 함(Mann–Whitney U test, 타깃을 표본 단위로) |
| 내부 일관성 | LIT-PCBA "full" vs "unbiased" 세트 | 같은 타깃 내에서 "unbiased" 세트의 AVE bias 점수가 "full" 세트보다 유의하게 낮아야 함(설계 의도와 일치하는지 검증) |
| 실제 성능과의 관계 | 편향 점수 vs 문헌 보고 AUROC/EF1% | 타깃별 편향 점수(3지표)와 공개된 벤치마크 결과(예: 3D-CNN, docking 기반 스코어링 등)의 성능 지표 간 Pearson/Spearman 상관계수 산출. 상관이 유의하게 높다면 "보고된 고성능이 편향에서 기인했을 가능성"에 대한 정량적 근거가 됨 |
| PDBbind 대비 액티브 분포의 이질성 | 물성 KS statistic, 화학공간 거리 | DUD-E/LIT-PCBA 액티브 세트 vs PDBbind 전체 리간드 분포 간 물성 편향 지표를 동일하게 계산해, 벤치마크 액티브 자체가 "실제 결합 화합물의 일반적 분포"에서 얼마나 벗어나 있는지 정량화 |
| 재현성/견고성 | AVE bias 반복 분할 표준편차 | 반복 횟수(5/10/20/50회)에 따른 점수 수렴 여부 확인 — 표준편차가 충분히 작아지는 반복 횟수를 확정해 보고 신뢰구간을 명시 |

### 5.2 정성 평가

- **화학공간 시각화**: 타깃별 액티브/디코이의 ECFP4 지문을 UMAP/t-SNE로 2차원 투영해, 편향 점수가 높은 타깃(예: DUD-E 특정 타깃)에서 두 클래스가 시각적으로도 뚜렷이 분리되는지, 편향 점수가 낮은 타깃(LIT-PCBA unbiased)에서는 섞여 있는지 정성적으로 대조.
- **대표 사례(케이스 스터디) 분석**: 편향 점수가 가장 높은/낮은 상위 3개 타깃을 선정해, 어떤 디스크립터·어떤 골격이 편향을 주도하는지 구체적으로 제시(예: "이 타깃의 디코이는 전부 고리가 없는 지방족 사슬이라 골격 편향이 1.0에 근접").
- **문헌 주장과의 정합성 검토**: Chen et al.(2019)이 개별적으로 지적한 특정 DUD-E 타깃(예: 논문에서 물성만으로 분리 가능함을 보인 사례)에 대해, 본 도구가 동일하게 높은 물성 편향 점수를 산출하는지 교차 검증 — 기존 정성적 지적을 본 도구가 정량적으로 재현할 수 있음을 보이는 것이 도구의 신뢰성을 뒷받침하는 핵심 근거가 된다.

### 5.3 예비 검증 결과 (실제 데이터, 타깃 1개씩)

본격적인 전체 타깃 대상 평가(§5.1, §5.2)에 앞서, 파이프라인이 실제 공개 데이터에서 의미 있는 신호를 내는지 확인하기 위해 각 데이터셋에서 가장 작은 타깃 하나씩을 받아 실행했다. LIT-PCBA는 15개 타깃 중 inactive 수가 가장 적은 **TP53**(actives 79 / inactives 4,168), DUD-E는 **AMPC**(actives 48 / decoys 2,850)를 사용했다. PDBbind는 계정 등록 없이는 자동 확보가 불가능함을 실제로 확인했고(§3.3), 동일 역할을 하는 RCSB 공개 API 기반 실측 결합친화도 참조 세트(고유 리간드 207개)로 대체해 비교했다.

**액티브 vs 디코이 (3지표):**

| 지표 | TP53 (LIT-PCBA) | AMPC (DUD-E) |
|---|---|---|
| property_bias | 0.183 | 0.284 |
| scaffold_bias (rarefied) | 0.952 (raw 0.985) | 0.979 (raw 0.997) |
| active_scaffold_coverage | 39.1% | 18.5% |
| ave_bias | 0.413 | 0.532 |

세 지표 모두 방향이 일관되게 "DUD-E(AMPC)가 LIT-PCBA(TP53)보다 더 편향됨"을 가리켰다 — LIT-PCBA가 이 편향들을 줄이도록 설계됐다는 §2 문헌 주장과 정확히 부합한다. 타깃 1개씩이라 통계적 유의성을 주장할 단계는 아니지만, §5.1의 본 평가(다수 타깃, 유의성 검정)를 수행하기 전에 지표들이 올바른 방향으로 작동함을 보여주는 예비 근거로 확보했다.

**액티브 vs RCSB 실측 결합친화도 참조 세트:**

| 지표 | TP53 actives | AMPC actives |
|---|---|---|
| property_bias | 0.185 | 0.296 |
| scaffold_bias | 0.953 | 0.950 |

두 타깃 모두 참조 세트 대비 물성·골격 편향이 상당히 존재한다. 다만 scaffold_bias는 해석에 주의가 필요하다 — 참조 세트는 여러 타깃에 걸친 다양한 화합물의 모음이고, 액티브는 "이 특정 단백질 하나에 결합하는" 화합물이므로, 애초에 특정 타깃의 의약화학적 계열(chemical series)이 참조 세트 전체와 scaffold를 공유하지 않는 것은 자연스러운 현상이지 편향의 증거가 아니다. 따라서 이 비교에서는 **물성 편향만 "일반적인 결합 화합물 분포에서 벗어난 정도"로 의미 있게 해석**하고, scaffold_bias는 참고용으로만 사용하기로 한다 — 이 구분은 §4.2/§5.1 본문에도 반영해야 할 방법론적 교정 사항이다.

**이번 예비 검증에서 얻은 방법론적 개선**: 위 TP53 단일 사례 검증 도중 scaffold_bias의 클래스 크기 불균형 취약성이 발견되어 rarefaction 보정을 추가했다(§4.2). 이는 소규모 실데이터 검증을 먼저 수행한 것이 방법론 결함을 조기에 드러내 전체 평가 이전에 지표를 교정할 수 있게 했다는 점에서, §5.1의 "지표 자체의 타당성" 검증 단계를 실제로 선행 실시한 사례이기도 하다.

### 6.4 마일스톤 / 체크포인트

- **1주차 말**: 전체 데이터 확보 여부 확정 — 늦어지면 이후 일정 전체가 밀리므로 가장 먼저 리스크 관리
- **4주차 말**: 중간 점검 — 여기까지 지표 타당성 통계 검정과 케이스 스터디 초안이 나와 있어야 5~7주 집필이 정상 진행 가능
- **7주차**: 논문 제출 및 코드 저장소 최종 태그

### 6.5 위험 요소 및 대응

| 위험 | 실제 발생 여부 | 대응 |
|---|---|---|
| PDBbind 계정 없이는 다운로드 불가 | 이미 발생(§3.3) | RCSB API 대체 경로 유지, 계정 신청은 병행하되 일정에 반영하지 않음 |
| 대형 타깃(ALDH1: actives 5,363 / decoys 101,874 등) 연산 시간 폭증 | 미발생, 예상되는 리스크 | `ave_max_reference`(기본 2000)로 참조 집합 상한 유지, 필요시 멀티프로세싱으로 타깃 단위 병렬화 |
| LIT-PCBA 15개 타깃만으로 통계적 유의성 확보 어려움 | 예상되는 리스크 | 비모수 검정(Mann–Whitney) 사용, 타깃 페어링(같은 단백질 계열) 매칭 비교로 표본 효율 보완 |
| 팀원 간 코드 충돌/중복 작업 | 예상되는 리스크 | 역할별 모듈 경계(§6.2)를 디렉토리 단위로 유지, 모든 변경은 PR 리뷰 후 병합 |

### 6.6 운영 방식

- 주 1회 정기 싱크(진행 상황 공유, 블로커 확인), 이슈/작업은 저장소 이슈 트래커로 관리
- 모든 코드 변경은 PR + 최소 1인 리뷰 후 병합, `pytest` 통과가 병합 조건
- 본 제안서(`doc/제안서.md`)는 매주 결과가 갱신될 때마다 함께 갱신해 "현재 시점의 최신 상태"를 유지
